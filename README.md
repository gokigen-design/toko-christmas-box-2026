## 2026/10/30 スマホ検品で直したところ

- `assets/word-cards/` に英単語8語を元PDFから切り直し（上下左右の欠けをなくし、白い背景を透過）。旧 `word-icons/` は残してある
- `assets/clean-crops/count-game-trim.webp` と `recipe-photo-trim.webp` はふちの白い帯を落とした版。旧ファイルは残してある

- 日本語は文節で折る（word-break: auto-phrase）。見出しは意図した位置で改行

## 2026/10/30 レシピとカウントゲームの作り込み

- `assets/recipe/` 材料9点（ing-）と手順7枚（step-）を2025年版PDFの2ページ目・4ページ目から切り抜き
- 作り方はPDFと同じ7手順。手順ごとに写真と語りかけ編の英語の声かけ（PDF5ページ目）を付けた
- 語りかけ編の enouth は enough に直した。It looks Rudolph はPDFのまま
- `assets/count-targets/` さがすもの10こ（PDF9ページ目の下の枠）。カードの＋と−で数を数えられる
- スマホではカウントの絵が上に止まったまま、下のカードを押せる。絵をタップすると大きく開く
- `assets/pdf-thumbs/` 印刷ボタンの上に置いたPDF見本3枚
